One-line: the Progress-screen metric switch (Strength / Volume / 1RM / Body) and any 2–4 way exclusive choice.

```jsx
<SegmentedControl options={['Strength','Volume','1RM','Body']} value={metric} onChange={setMetric} />
```

Selected segment takes the lime fill on a graphite track. Beyond four options the labels stop fitting Polish strings — use `Select`.
