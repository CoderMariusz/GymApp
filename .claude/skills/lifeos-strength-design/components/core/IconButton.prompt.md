One-line: circular icon-only control for headers and toolbars; `label` is mandatory.

```jsx
<IconButton icon="bell" label="Notifications" />
<IconButton icon="pause" label="Pause rest timer" variant="filled" />
```

Variants: ghost (headers) · filled (on cards, e.g. timer pause) · accent (lime, the workout FAB). Box never smaller than 44px even when the glyph is 16px.
